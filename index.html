What we watch

The silent changes that cost your clients search traffic — and cost you the awkward phone call. We report technical changes, never guesses about rankings.

New noindex directives

The most expensive silent accident in SEO: a page tells Google to drop it from results. We catch it in the HTML or the response headers, the day it happens.

robots.txt changes

A new rule blocks crawlers from a page that matters. We check the rules that apply to every monitored page — and explain them in plain English.

Canonical changes

When a canonical moves, search credit moves with it — including the classic disaster: canonicals still pointing at the staging domain after launch.

Errors & redirect problems

Pages that stop loading (4xx/5xx), redirect loops, and chains that keep growing after a redesign or migration.

SSL certificate expiry

Warnings at 30, 14, and 7 days before a certificate expires — because an expired cert turns your client's site into a browser security warning.

Sitemap drops

A key page falls out of the sitemap after a rebuild. It can still be found — but you should know it happened.

Title & heading changes

A plugin update rewrites the titles you optimised. We diff the title tag and main heading on every monitored page.

HTTP → HTTPS

If the insecure version of a page stops redirecting to the secure one, visitors and search engines can end up in the wrong place.

Honest answers

Does LaunchGuard fix the problems it finds?

No — LaunchGuard detects and explains. It never touches your clients' websites. Fixing stays with you (or your developer), which is exactly how agencies told us they want it. If you'd rather hand a fix off, tell us in a reply and we'll point you to people who can.

Will it tell me if a page loses its Google ranking?

No, and be wary of any tool that promises that. LaunchGuard reports technical changes — the things that cause ranking losses — the moment they happen, while they're still cheap to reverse.

What if a change was planned — a redesign, a title rewrite?

Mark it "expected" from the alert. That signal re-baselines, so you won't hear about it again. LaunchGuard is built to be quiet when nothing is wrong.

Which websites does it work with?

Any public website — WordPress, Shopify, Wix, custom builds. If a browser can open it, LaunchGuard can watch it. Extra Shopify-aware checks (products going unpublished, checkout reachability, policy pages) are rolling out to all plans.

How do alerts reach me?

By email, immediately for critical changes, after a confirmation re-check so a one-off glitch never wakes you up. Everything else rolls into the weekly summary.

Can I cancel anytime?

Yes. Subscriptions run through Stripe; cancel from the link in any payment email, or just email us and we'll do it for you. No retention scripts, no dark patterns.
